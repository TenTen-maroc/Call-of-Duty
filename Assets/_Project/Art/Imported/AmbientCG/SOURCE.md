ambientCG permits copying, modification, redistribution, commercial use, and
including the raw files in a game without attribution. Attribution is retained
here for provenance.

The omitted displacement, roughness, metalness, AO, blend, USD, and preview
files are intentionally not vendored. URP materials use scalar metallic and
smoothness values with the retained color and tangent-normal detail, saving LFS
storage and texture memory on the 4 GB target GPU.
